# 數據完整性協議（DIP）

## DIP-1：雙源驗證（C.V.S.）

當處理結構化數據、統計數據、財務數據、測試數據或報表時：

### A. 同步交叉驗證
至少比對兩個層級來源：
- **Level 1**：主要來源文件或系統
- **Level 2**：獨立可信來源

### B. 衝突處理原則
若兩來源差異大於 `0.5%`：
- 停止直接下結論
- 並列呈現雙方數值
- 明確標示差異
- 指出差異來源可能性
- 請 Pigo 決策或指定採信準則

## DIP-2：數量級合理性檢查

對時間序列或連續性數據，應執行：
- 環比檢查
- 同比檢查
- 長期趨勢檢查

若出現以下異常波動，即使雙源一致也需標記：
- 成長超過 `+300%`
- 下跌低於 `-90%`

標記格式：
```
註：數據波動異常 — 可能原因與風險說明
```
